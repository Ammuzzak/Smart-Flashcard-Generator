# 📚 Smart Flashcard Generator

An interactive study application that converts learning material into question-answer flashcards.

## ✨ Features

- Accepts study material as text
- Identifies important concepts from the material
- Automatically generates question-answer flashcards
- Previous and Next flashcard navigation
- Random flashcard mode
- Interactive Self-Test Mode
- Answers are hidden until the student chooses to reveal them
- Mark cards as **Known** or **Need Revision**
- Track revision progress
- Filter cards by All Cards, Known, or Need Revision

## 🛠️ Technologies Used

- Python
- Streamlit

## ▶️ How to Run

1. Clone or download this repository.
2. Install the required package:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
streamlit run app.py
```

## 🎯 Challenge Requirement

The application includes a Self-Test Mode where answers are initially hidden. Students can reveal the answer and mark each flashcard as:

- ✅ Known
- 🔄 Need Revision
